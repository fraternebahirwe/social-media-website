**FratSocial** is a clean, responsive, Instagram-inspired social media web interface built using pure HTML, CSS, and vanilla JavaScript. It features an interactive feed with stories, post likes, real-time comment submissions, and a profile suggestion sidebar.

---

## ✨ Features

- **Responsive Layout:** Grid and Flexbox layout optimized for modern web browsers.
- **Story Bar:** Story highlights bar featuring user avatars.
- **Interactive Feed:**
  - Like button functionality with instant counter toggles.
  - Interactive comment section allowing users to add comments in real-time.
- **Sidebar Suggestions:** User profile navigation and follow suggestions.
- **Semantic HTML5:** Built with accessibility (`aria-label`, semantic tags) and standard SEO metadata in mind.

---

## 🛠️ Tech Stack

- **Markup:** HTML5 (Semantic Structure)
- **Styling:** CSS3 (Flexbox & CSS Grid)
- **Scripting:** Vanilla JavaScript (ES6 DOM Manipulation)
- **Typography:** Inter (Google Fonts)
